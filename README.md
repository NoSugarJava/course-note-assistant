# course-note-assistant
AI 课程笔记助手

AI 课程笔记助手 是一款面向学生和自学者的智能工具，旨在解决课堂拍照资料和电子教材难以整理、阅读效率低下的痛点。通过结合 OCR 识别与大语言模型，自动将零散的课件截图、PDF 教材转化为结构清晰的 Markdown 笔记、思维导图大纲和重点摘要，大幅提升学习效率。

场景痛点
上课拍摄了大量 PPT 照片，后续懒得整理或整理成本高。

拥有多本 PDF 教材，阅读耗时长，难以快速抓住核心内容。

缺乏自动化的笔记生成工具，手动整理易遗漏重点。

核心功能
课件截图 → Markdown 笔记
上传课件截图（如 PPT 照片），系统通过 OCR 识别其中的文字，再由 AI 自动整理为格式规范的 Markdown 笔记。

PDF 教材 → 思维导图大纲 + 重点摘要
上传 PDF 教材，AI 自动提取关键章节与核心观点，生成可用于思维导图的层级大纲，并附带全文重点摘要。

技术栈
后端框架：Spring Boot

AI 能力：Spring AI（集成大语言模型进行内容整理与摘要）

OCR 识别：百度 OCR 免费版（提供免费额度）

向量数据库：Chroma（轻量级，可运行在本地内存，零成本起步）

项目优势
零成本起步：百度 OCR 提供免费额度，Chroma 支持本地内存运行，无需付费云服务。

轻量化部署：基于 Spring Boot，可轻松打包运行在个人电脑或低配置服务器。

高效自动化：从原始材料到结构化笔记全流程自动完成，节省大量手动整理时间。

易于扩展：Spring AI 框架便于接入更多 AI 模型，未来可增加语音转文字、多模态笔记等功能。

首次使用前在前端的 设置-settings 页面输入：
百度 OCR API Key + Secret Key
阿里百炼 API Key
LLM Model（默认 qwen-plus）
